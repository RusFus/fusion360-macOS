# RusFusionEXE для macOS

Русификатор интерфейса Autodesk Fusion 360 для macOS

**Примечание:** Это неофициальный проект. Автор программы не связан с компанией Autodesk.

## Как установить

1. Скачайте файл `rusificator_mac.py`
2. Откройте Терминал
3. Запустите программу:
   ```bash
   python3 rusificator_mac.py
   ```

## Требования

- macOS 10.15 или новее
- Python 3.6+ (встроен в macOS)
- Autodesk Fusion 360
- Интернет не требуется — файлы русификации встроены в программу

## Что делает программа

- Автоматически находит установленный Fusion 360
- Использует встроенные файлы русификации (интернет не нужен)
- Устанавливает русский язык в интерфейс
- Позволяет удалить русификацию

## Где ищет Fusion 360

Программа проверяет следующие пути:
- `~/Library/Application Support/Autodesk/webdeploy/production/`
- `/Applications/Autodesk/webdeploy/production/`

## Файлы русификации

Все файлы русификации встроены в `rusificator_mac.py` — отдельно скачивать их не нужно.
При запуске программа распаковывает их во временную папку `~/.fusion360_rusificator_temp`:
- `russian_ru.xml` — перевод интерфейса
- `ru-html.zip` — русская справка (распаковывается в `ru-html/`)
- `ru-RU.zip` — таблицы строк (распаковывается в `ru-RU/`)

Если автоматическая установка не сработала, см. `инструкция для ручной установки.txt`.
В архиве также есть папка `Файлы для ручной установки` с этими тремя файлами — она нужна только для ручной установки.
